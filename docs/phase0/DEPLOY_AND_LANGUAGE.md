# Деплой и язык

Phase 0 ничего не меняет на Render и не меняет приветствие чата.

## Флаг социальной стипендии

- Код: `SCENARIO_SOCIAL` по умолчанию выключен (`app/scenarios/social.py`). Незаданная переменная тоже выключена.
- `.env.example` явно ставит `SCENARIO_SOCIAL=0`.
- `render.yaml` этот флаг не задаёт. Blueprint в этой фазе не редактировался.
- 2026-11-09 `GET https://ur-asystent.onrender.com/api/status` вернул `scenario_social: true`, `llm: true`, `provider: anthropic`, `chunks: 6406`.
- Тот же вызов не содержит git SHA. Совпадение живого деплоя с `bf64151` статусом не доказано. Совпадает только число чанков с индексом этой ветки.
- `QUALITY.md` пишет, что на деплое флаг выключен. Это расходится с ответом статуса от 2026-11-09. Включать флаг в коде из-за живого статуса нельзя: локальный дефолт остаётся выключенным.
- Первый `GET /healthz` в том же аудите не уложился в 20 секунд. Повторный статус после этого ответил. Это похоже на холодный старт free-плана, не на измерение здоровья.

Платный чат живого сайта не вызывался.

## Монгольский

Решение владельца, в этой фазе не принято.

- Задание перечисляет монгольский среди языков.
- `app/lang.py` переводит монгольский вход в английский ответ и не возвращает `mn`.
- Строки `mn` в уточнениях и отказах ещё лежат в коде, детектор их не выбирает.
- Приветствие `app/static/index.html` обещает ответ по-монгольски. Текст не менялся.
- Кейс `p0-holdout-xlang-01` помечен `clarification` и `UNCONFIRMED`. Он не утверждает ни монгольский, ни английский текст ответа.

Пока владелец не выберет «только вход» или «ещё и ответ», оба варианта остаются открытыми.
