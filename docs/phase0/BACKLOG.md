# Бэклог фаз 1–6

Список пробелов относительно ТЗ. В Phase 0 это не реализуется.

## Фаза 1 — ingestion

Сделано в коде, без Postgres и без пересборки боевого `data/index.npz`. Подробности: `docs/phase0/PHASE1.md`.

- Allowlist: `data/allowlist.yaml`. Краулер читает его и не добавляет хосты из кода. 2026-11-09 владелец включил пять официальных доменов из фактов (`euczelnia`, `sjo`, `www.erasmusplus.org.pl`, `www.gov.pl`, `dziennikustaw.gov.pl`). Выключены `kn`, `wicit`, `static1.squarespace.com`, `isap.sejm.gov.pl`, `odyseusz.msz.gov.pl`.
- DNS, IP и каждый редирект проверяются. Private, loopback, link-local и metadata отклоняются (`app/fetch_public.py`).
- HTML 5 МБ, PDF 20 МБ / 200 страниц, robots, timeout 15 с, два повтора с jitter.
- Ревизии файлового индекса: идемпотентный импорт, атомарный указатель CURRENT, rollback (`app/index_revision.py`). Сервер по-прежнему отдаёт уже собранный `data/index.npz` и сам его не строит.

## Фаза 2 — retrieval

Сделано отдельно от кода ответов модели. Подробности: `docs/phase0/PHASE2.md`.

- FAQ и синонимы лежат в `data/faq.yaml` и `data/synonyms.yaml`. Быстрый путь не вызывает LLM и эмбеддинги. Порог ТЗ: confidence ≥ 0.95 и margin ≥ 0.15.
- Hard filters стоят до лимита результата. Пустой год, факультет, срок или ревизия не означают «подходит всем».
- Каталог faculty/program ID пустой (`data/canonical_ids.yaml`). Неизвестный явный ID уточняется, а не угадывается.
- Поиск файла остаётся BM25 + n-граммы. Веса evidence gate на holdout не калибровались. Оценка 40 кейсов остаётся `not measured`.

## Фаза 3 — answer

- JSON-схемы intent и answer из ТЗ, temperature 0, без второго «ремонтного» вызова модели.
- Цитаты только из манифеста. URL не собирать из предложения модели — этот запрет в коде уже есть и его не ослаблять.
- SSE со статусом, источниками и текстом после проверки. Сейчас ответ одним JSON.
- Живой eval только после отдельного OK на модель, число вызовов и бюджет.

## Фаза 4 — cache и стоимость

- Ключ ответа без session id и user id. Сейчас кэша ответа нет, сессия — HMAC в браузере.
- TTL и single-flight. Лимит по HMAC идентификатора, без сырого IP в логе. Сейчас IP пишется в лог `ur.api`.
- Цена токена: неизвестная цена — `unknown`, не ноль. Прайс не выдумывать.

## Фаза 5 — admin

- `/admin/ai`, RBAC, аудит настроек, dry-run индекса.
- Секреты в админку не вводить и не показывать.
- Метрики не обещать, пока нет журнала запросов.

## Фаза 6 — hardening

- Набор 40 после подписи владельца, цель ТЗ ≥36/40 и holdout ≥9/10. До подписи оценка скелета — `not measured`.
- Нагрузка 10 одновременных запросов, retention, backup. На free-плане Render диск эфемерный, индекс живёт в образе.
- Провайдер недоступен → шаблон со ссылками или отказ, не ответ «из головы». Фолбэк без ключа уже есть; таймауты и пороги ТЗ (6 с, circuit breaker) не включены.

Старые 103 диалога в `tests/cases.yaml` остаются регрессией языка и слотов. Они не становятся rubric 0–4.
